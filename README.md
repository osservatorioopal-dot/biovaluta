# BioValuta — Valuta la tua Startup Biotech

Piattaforma didattica interattiva per l'esercitazione di **valutazione degli investimenti** (VAN, TIR, Payback) nel corso di Biotecnologie.
Il caso studio: gli studenti sono il team di *BioSensor S.r.l.*, una startup di kit diagnostici, e devono convincere un investitore.

## Contenuti

- **📖 Lezione** — percorso guidato in 5 passi con i dati reali del mercato biotech (mondo e Italia)
- **🧪 Simulatore** — slider per investimento, flussi di cassa e tasso di sconto; VAN, TIR e Payback calcolati in tempo reale, con grafico dei flussi e verdetto
- **🎯 Quiz** — 6 domande a risposta multipla con spiegazioni e punteggio finale

## Materiali collegati

- `Esercitazione_VAN_Startup_Biotech.xlsx` — workbook Excel con analisi di mercato, teoria passo passo, caso guidato ed esercizi
- `Guida_Valutazione_Investimenti_Biotech.docx` — guida per l'insegnante

## Avvio in locale

```bash
npm install
npm run dev        # sviluppo
npm run build      # produzione in dist/
```

Dati di mercato: Mordor Intelligence (2025), Report Assobiotec-Federchimica 2025, Tufts CSDD / DiMasi, BIO-Biomedtracker, DealMaker.
